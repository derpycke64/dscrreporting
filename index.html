// 03 DEFINITION
What is a Tree?




Tree
A tree is a connected, undirected graph with no simple circuits. A forest is a graph whose components are all trees.


Rooted tree
Pick one vertex as the root and direct every edge away from it. Any vertex of a tree can be the root, and different roots give different rooted trees.


Equivalent statements (T has n vertices)
  • T is connected and has no circuits
  • There is a unique simple path between any two vertices
  • T is connected, and removing any edge disconnects it
  • T is connected and has n − 1 edges
  • T has no circuits and adding any edge creates exactly one circuit


> Tap a vertex. Same tree, any vertex can be the top.

// WATCH OUT
Myth or Fact?
Open each card. These are common misconceptions.




MYTH: any graph with n − 1 edges is a tree
FACT: it must also be connected (or acyclic). A triangle plus a separate edge has 5 vertices and 4 edges but is not a tree.


MYTH: the root is special and always sits at the top
FACT: in a plain tree any vertex can be chosen as the root. Drawing it top-down is only a convention.


MYTH: height counts the vertices on the longest path
FACT: height counts edges. A single vertex has height 0, and the root is on level 0.


MYTH: a vertex in a tree can have two parents
FACT: every non-root vertex has exactly one parent. A second parent would create a circuit.


MYTH: a leaf must be on the bottom level
FACT: a leaf is any vertex with no children, on any level.


MYTH: full and complete trees are the same thing
FACT: full means every internal vertex has all m children. Complete means every level is filled, with the last filled from the left.

// 08 CLASSIFICATION
Types of Rooted Trees




m-ary
A rooted tree is m-ary if every internal vertex has at most m children; full m-ary if exactly m. m = 2 gives a binary tree. A balanced tree of height h has all leaves at level h or h − 1.

// 10 IN THE WILD
Where Trees Live


A tree shows up whenever data is hierarchical: one starting point, branches that never loop back, and every item hanging from exactly one parent. Six places you meet that shape every day:




File system
Folders hold files and other folders, and nothing links back upward, so a whole drive is one rooted tree.
C:/
├ Users
│ └ docs
└ Windows
ROOT drive · INTERNAL folders · LEAVES files


HTML document
Every tag sits inside exactly one parent tag. Browsers keep a page as a tree so they can render and style it.
html
├ head ─ title
└ body
  ├ h1
  └ ul ─ li, li
ROOT html · LEAVES text and empty tags


Org chart / family tree
Each person reports to exactly one boss (or has one parent line), which gives a clean hierarchy with no cycles.
CEO
├ CTO ─ dev, QA
└ CFO ─ audit
ROOT CEO · LEVEL = rank


Decision tree
Each question splits the cases into branches until an answer is reached. Used in programming and machine learning.
raining?
├ yes → umbrella
└ no  → sunny?
        ├ yes → cap
        └ no  → go
INTERNAL questions · LEAVES decisions


Expression tree
Operators become internal vertices and numbers become leaves, so the shape itself encodes the order of operations.
(3 + 4) × 5
    ×
   / \
  +   5
 / \
3   4
INTERNAL operators · LEAVES numbers


Database index
Balanced search trees keep a lookup near log2 n steps: about 20 comparisons for a million records.
      50
    /    \
  25      75
 /  \    /  \
10  30  60  90
LEFT smaller · RIGHT larger
